vCard Generator Engine (vCGE)

This app cannot run in this browser

vCGE keeps your contacts on this device, with no internet. This browser is missing something vCGE needs to keep that promise, so the app did not start. Nothing was read, saved or sent.

What’s missing

    Free & open source browsers (recommended)

    • Firefox By Mozilla, a nonprofit. Open source (MPL 2.0), with strong tracking protection.
    • Firefox ESR for Windows 7, 8 and 8.1 On older Windows, Mozilla says it keeps sending security updates to Firefox ESR 115 until March 2027.
    • Brave Open source (MPL 2.0). Blocks trackers and ads by default.

    Other current browsers

    • Microsoft Edge Windows, Mac, Android, iPhone.
    • Google Chrome Windows, Mac, Linux, Android, iPhone.
    • Safari Mac, iPhone and iPad (keep the system up to date).

    These links open each browser maker’s own website. vCGE sends nothing with them.
